three databases and roles from `test-support/src/main/resources/db/init.sql` with random passwords,
runs Flyway as the service's own role, and tests over HTTP on a random port.

## Two test mistakes caught on the way

- The helper that runs `init.sql` split statements on `;` before removing comments, and the header
  comment contains a `;`. Fixed by stripping comments first.
- `new Object()` was meant to make the event write fail, but Jackson 3 serialises it as `{}`. The
  test now uses a payload whose getter throws, so it really exercises the failure path.
